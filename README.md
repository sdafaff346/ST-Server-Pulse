# Server Pulse (서버 상태 예측)

AI 서버 상태를 자동으로 기록하고, 가끔 묻는 내 평가(1~5점)를 학습해 지금과 앞으로 24시간 상태를 예측합니다.

## 설치
1. SillyTavern의 확장(Extensions) 패널 → **확장 설치(Install extension)**
2. 아래 주소를 붙여 넣고 설치
   `https://github.com/sdafaff346/ST-Server-Pulse`
3. 업데이트는 확장 패널의 업데이트 버튼으로 받을 수 있어요.

## 자동으로 기록하는 것
- 생성마다: 성공/실패(에러 알림·빈 응답 = 실패, 직접 멈춘 건 제외), 전체 응답 시간, 첫 토큰까지 시간, 연결(소스/모델)
- API 직접 측정: 기본 30분마다 "OK"만 답하라는 아주 짧은 요청(기본 최대 16토큰)을 보내 실제 성공 여부와 응답 시간을 기록. 그 사이 실제 생성이 있었으면 건너뜀. 연결 프로필을 고르면 그 프로필의 API·모델로 **측정 프롬프트만** 보냄(프리셋·캐릭터·채팅 없음). 시스템 프롬프트, 유저 메시지, 최대 토큰은 설정에서 바꿀 수 있음. 결과는 지금 쓰는 연결의 예측에 반영됨
- 핑: SillyTavern 서버 + 직접 추가한 주소 (기본 5분마다)
- 평가: 기본 60분마다, 그 사이 생성이 1번 이상 있었을 때만 알림으로 1~5점을 물어봄

## 예측 방식
- 시간대: 비슷한 시간(±1.5시간), 같은 평일/주말의 과거 평가를 최근일수록 크게(반감기 21일) 반영
- 실시간: 최근 30분 생성 실패율, 평소 대비 응답 속도, API 측정 실패율, 핑 실패율 → 평가가 6개 이상 쌓이면 내 평가로 학습한 회귀 모델을 섞어 씀
- 방금(1시간 이내) 준 평가가 있으면 그걸 가장 크게 반영
- 평가가 같은 연결로 5개 이상이면 그 연결 데이터만 사용(설정에서 끌 수 있음)

## 화면
- 배지: 현재 예측 점수 (클릭 → 대시보드). 위치는 설정에서 네 모서리 중 고를 수 있음
- 마술봉(확장) 메뉴의 "서버 상태"로도 대시보드를 열 수 있음
- 대시보드: 현재 점수·이유·신뢰도, 24시간 예측 막대, 요일×시간 히트맵, 연결별 통계, 핑 가동률
- 슬래시 명령: `/pulse` (대시보드, 점수 반환), `/pulse-rate 4`, `/pulse-probe` (지금 측정)

모든 기록은 이 브라우저에만 저장됩니다(localforage). 다른 기기로 옮기려면 내보내기/가져오기를 쓰세요.
