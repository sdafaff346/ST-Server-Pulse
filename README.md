# Server Pulse (서버 상태 예측)

AI 서버 상태를 자동으로 기록하고, 가끔 묻는 "방금 답장 어땠어요?" 평가를 학습해
**지금 보내면 답장이 올지**와 **온다면 좋은 답장일지**를 예측합니다. 앞으로 24시간 예측도 보여줘요.

## 설치
1. SillyTavern의 확장(Extensions) 패널 → **확장 설치(Install extension)**
2. 아래 주소를 붙여 넣고 설치
   `https://github.com/sdafaff346/ST-Server-Pulse`
3. 업데이트는 확장 패널의 업데이트 버튼으로 받을 수 있어요.

## 평가 (v1.4)
답장이 온 직후에 가끔(기본 45분마다) 알림으로 물어봐요.

| 버튼 | 뜻 | 예측에서 |
|---|---|---|
| 🚫 안 옴 | 답장이 안 오거나 끝없이 기다림 | "답장 올 확률"을 깎음 |
| 💥 캐붕·고장 | 답장은 왔는데 망가짐 (캐붕, 깨진 글, 반복, 엉뚱한 말) | "답장 질" 학습 |
| 😐 노잼 | 멀쩡하게 왔는데 재미없음 | "답장 질" 학습 |
| 😊 좋음 | 만족 | "답장 질" 학습 |

대시보드에서 언제든 직접 남길 수 있고, `/pulse-rate 노잼` 처럼 슬래시 명령으로도 돼요 (`안옴` · `캐붕` · `노잼` · `좋음`).
예전 1~5점 평가는 1 → 안 옴, 2 → 캐붕, 3 → 노잼, 4·5 → 좋음으로 자동으로 바뀌어요(조금 낮은 비중으로 반영).

## 자동으로 기록하는 것
- 생성마다: 답장 옴 / 안 옴, 첫 글자까지 시간, 전체 응답 시간, 연결
  - 에러(429, 5xx, 끊김), **빈 답장**, **무한 대기**(아무 글자도 안 온 채로 20초 넘게 기다리다 멈춤)는 "답장 안 옴"
  - 글자가 오기 시작한 뒤 멈춘 것, 금방 멈춘 것은 기록에서 빼요
  - 다른 확장이나 컨텍스트 초과 같은 내 쪽 문제는 서버 실패로 치지 않아요
- 망가진 답장 자동 감지(약한 단서): 같은 문장·말 반복, 깨진 글자, 다른 언어 섞임, 평소보다 너무 짧게 끊김
- API 직접 측정: 기본 30분마다 "OK"만 답하라는 아주 짧은 요청. 그 사이 실제 생성이 있었으면 건너뜀
- 핑: SillyTavern 서버 + 직접 추가한 주소 (기본 5분마다)

## 연결별 기록
- **Vertex AI**: 리전(global, us-central1 등)별로 따로
- **NanoGPT**: 프로바이더별로 따로 (자동 라우팅은 하나로). 잔액 부족은 서버 문제가 아니라 설정 문제로 쳐요
- 이 연결의 평가가 5개 미만이면 답장 질은 전체 평가를 참고해요

## 예측 방식
- 답장 올 확률: 최근 20분 기록을 가장 크게, 이 시간대(요일·시간)의 평소 기록을 바탕으로
- 답장 질: 같은 시간대의 내 평가로 좋음·노잼·캐붕 비율을 학습. 방금 한 평가일수록 지금 예측에 크게 반영
- 점수 = 답장 올 확률 × 답장 질 − 느려진 정도
- 429·과부하 직후에는 "보통 몇 분 뒤 회복되는지" 알려줘요

## 화면
- 배지: 지금 답장이 올 가능성(%) + 걱정되는 점(💥 캐붕 / 😐 노잼 / 😊 좋음). 클릭 → 대시보드
- 대시보드: 답장 올 확률, 답장 질 막대, 이유, 24시간 예측(막대 위 💥·😐 = 그 시간 주의), 요일×시간 히트맵, 연결별 평가, 생성·측정·핑 기록
- 슬래시 명령: `/pulse` (대시보드, 답장 올 확률 0~100 반환), `/pulse-rate 노잼`, `/pulse-probe` (지금 측정)

모든 기록은 이 브라우저에만 저장됩니다(localforage). 다른 기기로 옮기려면 내보내기/가져오기를 쓰세요.
